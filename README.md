# FormulaHub ETL

**Visual ETL for the modern data stack** — open source, AI-assisted, deploy anywhere.

FormulaHub ETL is a drag-and-drop pipeline designer. Underneath, it generates and runs clean Python jobs through a lightweight DAG runner. Git-native pipelines, no vendor lock-in.

**Product site:** [formulahub.io/etl](https://formulahub.io/etl)  
**Live UI (Vercel):** [formulahub-etl.vercel.app](https://formulahub-etl.vercel.app) — designer only; API still local/Docker  
**License:** [Apache License 2.0](./LICENSE)

---

## What you get

- **Visual canvas** — React Flow designer with colorful components on a clean white workspace
- **Field Mapper** — discover schema from sources, drag column→column mappings, edit expressions
- **AI Pipeline Builder** — describe a job in English; get a graph with mappings and Python Row stubs filled in
- **Param-first inspector** — configure nodes with simple forms, not raw JSON
- **Run animation** — watch edges and nodes animate while the job executes
- **Deploy anywhere** — local, Docker, or Kubernetes; pipelines are plain JSON/YAML

---

## Architecture

```
apps/web          React + Vite + React Flow (visual DAG)
packages/api      FastAPI — CRUD, run, logs, AI builder, schema discover
packages/runner   Python component SDK + sequential DAG runner
demos/            Ready-to-run pipeline demos
fixtures/         Sample data + PGP keys (generated by seed)
data/             Runtime mock S3 / outputs / archive
```

**Pipeline definition:** JSON/YAML DAG (`nodes` + `edges`).  
**Runtime:** Python 3.11+ (`FORMULAETL_DEMO=1` for local mock S3 & Snowflake).

## Quickstart

### Prerequisites

- Python 3.11+
- Node.js 20+
- (Optional) Docker + Docker Compose

```bash
make install   # editable Python packages + web deps
make seed      # PGP keys, encrypted CSV → data/s3/demo/
make test      # unit + integration + API tests
make demo      # run the spectacular pipeline CLI
```

### Run API + UI

```bash
# terminal 1
make api          # http://127.0.0.1:18765

# terminal 2
make web          # http://127.0.0.1:18766
```

Open the UI → load a demo → **Run pipeline**. Watch logs, rows processed, rejects, and duration.

Or with Docker:

```bash
make docker-up    # API :18765  ·  UI :18766
```

### Hosted UI vs API

The production UI at [formulahub-etl.vercel.app](https://formulahub-etl.vercel.app) is the static Vite app (`apps/web`). It does **not** run FastAPI or the Python runner on Vercel. Point a browser at the live UI for the canvas; run pipelines with `make api` / `make docker-up` (`FORMULAETL_DEMO=1`). See [docs/deploy.md](./docs/deploy.md) for Vercel project details and API hosting next steps (Railway / Fly / Render / Docker). Optional later: `CNAME etl.formulahub.io` → Vercel.

### Flagship demo

**S3 → PGP Decrypt → CSV Parse → Schema Validate → Transform → Snowflake (demo) → Archive**

In demo mode (`FORMULAETL_DEMO=1`, default) S3 and Snowflake use local filesystem mocks — no cloud credentials required.

## AI Pipeline Builder

`POST /api/ai/build` accepts English, e.g.:

> Read encrypted files from S3, decrypt using PGP, validate columns, reject invalid records, transform dates, load into Snowflake and archive processed files.

Returns a pipeline graph. With no LLM key, a solid offline heuristic still builds a demo-quality graph. With a key, it also auto-fills Field Mapper / Schema Map mappings and Python Row stubs from discovered schema.

## Development

```bash
FORMULAETL_DEMO=1 python -m formulaetl.cli run demos/s3-pgp-snowflake/pipeline.json
python -m formulaetl.cli components
cd apps/web && npm run build
```

**Honest demo boundaries:** Snowflake and S3 default to local mocks so anyone can run end-to-end without cloud accounts. Real connectors share the same interfaces when credentials and `FORMULAETL_DEMO=0` are set.
